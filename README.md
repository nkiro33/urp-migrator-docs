# URP Migrator docs

Website, manual and guides for **[URP Migrator](https://nkiro33.github.io/urp-migrator-docs/)**, a Unity editor tool that converts surface shaders, lit vertex/fragment shaders, GrabPass and OnRenderImage image effects from the Built-in Render Pipeline to URP. It keeps your materials and backs up every file it changes.

Get it on [Gumroad](https://neblaze4.gumroad.com/l/urp-migrator).

## Docs

- [Manual](https://nkiro33.github.io/urp-migrator-docs/manual.html): scan, preview, convert and revert; what gets converted; measured accuracy; command line ([PDF](URP-Migrator-Manual.pdf))
- [Built-in to URP migration checklist](https://nkiro33.github.io/urp-migrator-docs/guides/built-in-to-urp-checklist.html)
- [Convert surface shaders to URP](https://nkiro33.github.io/urp-migrator-docs/guides/convert-surface-shaders-to-urp.html)
- [GrabPass in URP](https://nkiro33.github.io/urp-migrator-docs/guides/grabpass-in-urp.html)
- [OnRenderImage in URP](https://nkiro33.github.io/urp-migrator-docs/guides/onrenderimage-in-urp.html)

`samples/` holds the example shaders used in the guides.

Plain HTML and CSS served by GitHub Pages from the `main` branch root, no build step.
