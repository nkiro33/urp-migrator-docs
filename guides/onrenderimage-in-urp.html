OnRenderImage in URP: port your image effects

In the Built-in pipeline, a script on the camera with OnRenderImage(source, destination) post-processes the frame with Graphics.Blit. URP never calls OnRenderImage, so these effects silently stop working. The same goes for OnPreRender, OnPostRender and command buffers added with Camera.AddCommandBuffer.

Tested code. The scripts and shaders compile on Unity 6000.0.84f1 with URP 17.0.4. Both URP options below produce the same image as the Built-in effect: 0.00/255 difference for the renderer feature and 0.00/255 for the Full Screen Pass (the effect itself changes the image by 26.20/255 on average).

The Built-in effect

VignetteEffect.cs (Built-in)
using UnityEngine;

// Built-in image effect: Unity calls OnRenderImage after the camera renders.
[ExecuteAlways, RequireComponent(typeof(Camera))]
public class VignetteEffect : MonoBehaviour
{
    public Material material;   // uses "Guide/Vignette (Built-in)"
    [Range(0, 1)] public float intensity = 0.5f;

    void OnRenderImage(RenderTexture source, RenderTexture destination)
    {
        material.SetFloat("_Intensity", intensity);
        Graphics.Blit(source, destination, material);
    }
}
Vignette shader (Built-in)
Shader "Guide/Vignette (Built-in)"
{
    Properties
    {
        _MainTex ("Texture", 2D) = "white" {}
        _Intensity ("Intensity", Range(0, 1)) = 0.5
    }
    SubShader
    {
        ZTest Always Cull Off ZWrite Off
        Pass
        {
            CGPROGRAM
            #pragma vertex vert_img
            #pragma fragment frag
            #include "UnityCG.cginc"

            sampler2D _MainTex;
            float _Intensity;

            fixed4 frag (v2f_img i) : SV_Target
            {
                fixed4 color = tex2D(_MainTex, i.uv);
                float2 d = i.uv - 0.5;
                color.rgb *= saturate(1.0 - dot(d, d) * _Intensity * 2.0);
                return color;
            }
            ENDCG
        }
    }
}

Step 1: port the shader

Both URP options draw a full-screen triangle with your material and pass the camera image in as _BlitTexture. Blit.hlsl provides the vertex shader (Vert), the Varyings struct and the texture:

Vignette shader (URP)
Shader "Guide/Vignette (URP)"
{
    Properties
    {
        _Intensity ("Intensity", Range(0, 1)) = 0.5
    }
    SubShader
    {
        Tags { "RenderPipeline"="UniversalPipeline" }
        ZTest Always Cull Off ZWrite Off
        Pass
        {
            Name "Vignette"

            HLSLPROGRAM
            #pragma vertex Vert
            #pragma fragment Frag
            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"
            // Full-screen triangle vertex shader (Vert) and the source texture (_BlitTexture).
            #include "Packages/com.unity.render-pipelines.core/Runtime/Utilities/Blit.hlsl"

            float _Intensity;

            half4 Frag (Varyings input) : SV_Target
            {
                UNITY_SETUP_STEREO_EYE_INDEX_POST_VERTEX(input);
                float2 uv = input.texcoord;
                half4 color = SAMPLE_TEXTURE2D_X(_BlitTexture, sampler_LinearClamp, uv);
                float2 d = uv - 0.5;
                color.rgb *= saturate(1.0 - dot(d, d) * _Intensity * 2.0);
                return color;
            }
            ENDHLSL
        }
    }
}

Option A: Full Screen Pass Renderer Feature (no code)

  1. Create a material with the URP shader.
  2. Select your Universal Renderer asset and click Add Renderer Feature ▸ Full Screen Pass Renderer Feature.
  3. Set Pass Material to the material and Injection Point to Before Rendering Post Processing. Leave Fetch Color Buffer on. If the shader reads depth or normals, tick them under Requirements.
  4. Delete the old script from the camera. Change the effect through the material (a script can set values on it at runtime).

This is the quickest route for one-pass effects. It runs for every camera using that renderer, and it can't run several passes with temporary textures the way a Graphics.Blit chain can.

Option B: your own renderer feature

For per-feature settings, several passes, or more control, write a renderer feature. This one uses Unity 6's render graph API:

VignetteFeature.cs (URP)
using UnityEngine;
using UnityEngine.Rendering;
using UnityEngine.Rendering.RenderGraphModule;
using UnityEngine.Rendering.RenderGraphModule.Util;
using UnityEngine.Rendering.Universal;

// URP replacement for the VignetteEffect OnRenderImage script: add it to the URP Renderer asset.
public class VignetteFeature : ScriptableRendererFeature
{
    public Material material;   // uses "Guide/Vignette (URP)"
    [Range(0, 1)] public float intensity = 0.5f;

    VignettePass m_Pass;

    public override void Create()
    {
        m_Pass = new VignettePass { renderPassEvent = RenderPassEvent.BeforeRenderingPostProcessing };
    }

    public override void AddRenderPasses(ScriptableRenderer renderer, ref RenderingData renderingData)
    {
        if (material == null) return;
        material.SetFloat("_Intensity", intensity);
        m_Pass.material = material;
        renderer.EnqueuePass(m_Pass);
    }

    class VignettePass : ScriptableRenderPass
    {
        public Material material;

        public VignettePass()
        {
            // The pass reads the camera color, so URP must render to a texture, not straight to the screen.
            requiresIntermediateTexture = true;
        }

        public override void RecordRenderGraph(RenderGraph renderGraph, ContextContainer frameData)
        {
            var resources = frameData.Get<UniversalResourceData>();
            if (resources.isActiveTargetBackBuffer) return;

            // source -> material -> new texture, which then becomes the camera color for later passes.
            TextureHandle source = resources.activeColorTexture;
            TextureDesc desc = renderGraph.GetTextureDesc(source);
            desc.name = "Vignette";
            desc.clearBuffer = false;
            TextureHandle destination = renderGraph.CreateTexture(desc);

            renderGraph.AddBlitPass(new RenderGraphUtils.BlitMaterialParameters(source, destination, material, 0), "Vignette");
            resources.cameraColor = destination;
        }
    }
}
  • requiresIntermediateTexture makes URP render the camera into a texture you can read.
  • AddBlitPass draws the material from source into a new texture, and setting resources.cameraColor makes later passes (post-processing, UI) use the result. For a multi-pass effect, chain blits through more textures from renderGraph.CreateTexture.
  • An effect marked [ImageEffectOpaque] becomes RenderPassEvent.BeforeRenderingTransparents. If the shader reads _CameraDepthTexture, call ConfigureInput(ScriptableRenderPassInput.Depth) on the pass.
  • If your project has the render graph turned off (Compatibility Mode in URP's Graphics settings), URP calls the older Execute method instead, so a feature for that mode needs one.
  • Don't call your class Vignette: URP already has a Vignette volume component, and the names clash in scripts that use UnityEngine.Rendering.Universal.

Add it with Add Renderer Feature ▸ Vignette Feature on the Universal Renderer asset. Downloads: VignetteFeature.cs, VignetteURP.shader.

Option C: keep your OnRenderImage code
