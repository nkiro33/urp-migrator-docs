Built-in to URP migration checklist

Unity is retiring the Built-in Render Pipeline. Its render pipeline strategy for 2026 deprecates it in Unity 6.5 with support in the 6.7 LTS until the end of 2028, and the path to a single render pipeline in Unity 7 makes it obsolete in Unity 7. This checklist covers what changes when a project moves to URP, in the order that causes the least rework.

1. Before you start

  • Commit everything to version control, or make a copy of the project.
  • List what will break. Search for #pragma surface, GrabPass, OnRenderImage, OnPreRender, OnPostRender, AddCommandBuffer, Projector, SetReplacementShader, and Shader.Find calls with Built-in shader names. URP Migrator's scan produces this list with what to do for each item, as an HTML, Markdown or CSV report.
  • Note the custom shaders that read _CameraDepthTexture or _LightColor0: they need URP settings or code changes.

2. Install URP and create the pipeline asset

  1. Install Universal RP from the Package Manager.
  2. Create a URP Asset (with Universal Renderer) from Assets ▸ Create ▸ Rendering ▸ URP Asset (with Universal Renderer).
  3. Assign it in Project Settings ▸ Graphics ▸ Default Render Pipeline and in every level of Project Settings ▸ Quality that should use it.
  4. Shadow distance, cascades and resolution now live on the URP Asset, not in the Quality settings. Set them again.

3. Convert Unity's own materials

Open Window ▸ Rendering ▸ Render Pipeline Converter, pick Built-in to URP, and run the converters you need: rendering settings, material upgrade (Standard, Legacy, Mobile and Particles shaders to their URP versions), read-only materials, animation clips, and Post Processing Stack v2 profiles if you use that package. This step does not touch materials that use your own shaders.

4. Convert custom shaders

  • Surface shaders: How to convert surface shaders to URP.
  • Vertex/fragment shaders that use ForwardBase/ForwardAdd, _LightColor0 or Built-in shadow macros: same approach (a UniversalForwardOnly pass with URP's Light functions, plus shadow and depth passes).
  • Unlit vertex/fragment shaders without a LightMode tag usually work in URP unchanged. They are not SRP Batcher compatible until their properties move into UnityPerMaterial.
  • GrabPass: GrabPass in URP.
  • Shaders that read _CameraDepthTexture: turn on Depth Texture on the URP Asset. Shaders in the transparent queue that read depth also need the renderer's Depth Texture Mode set to After Opaques.

5. Image effects and camera scripts

  • OnRenderImage effects: OnRenderImage in URP.
  • Post Processing Stack v2: use URP's Volume system (Bloom, Color Adjustments, Vignette, Depth of Field…).
  • OnPreRender/OnPostRender and camera command buffers: move the work into a renderer feature, or use RenderPipelineManager.beginCameraRendering/endCameraRendering for code that only sets state.
  • Replacement shaders: use a Render Objects renderer feature with an override material.
  • Several cameras layered by depth: use Camera Stacking (one Base camera with Overlay cameras).

6. Lighting and visuals

  • Point and spot lights fall off differently in URP (a physically based curve), so retune their range and intensity.
  • URP limits lights per object (set on the URP Asset). Forward+ removes that limit.
  • Rebake lightmaps, light probes and reflection probes.
  • Projectors don't render in URP: use the Decal Projector with the Decal renderer feature.
  • Halo and the Built-in Lens Flare component don't render: use Lens Flare (SRP).

7. Check everything

  • Look for pink materials in every scene and prefab (Console errors point to shader problems).
  • Check with point lights, shadows, fog and lightmaps, and in the rendering path you ship (Forward, Forward+ or Deferred).
  • Use the Frame Debugger to check SRP Batcher batches and that renderer features run.
  • Build for every target platform; shader compile errors can be platform-specific.
